# Atividade de Kubernetes

Siga o guia de instalação e a atividade em PDF publicados no Classroom.

Extraia este ZIP. A pasta devops_kubernetes contém os arquivos utilizados na prática. Todos os comandos são executados na raiz dessa pasta.

Windows: PowerShell, Python 3.10+, Docker Desktop com WSL 2 e Minikube. Ubuntu/Arch: Bash, Python 3.10+, Docker e Minikube.

Não são necessárias bibliotecas adicionais via pip. Os scripts kube.ps1 e kube.sh utilizam o contexto devops-k8s e o namespace aula-k8s. A pipeline está em scripts/pipeline_local.py.

Registre as observações em evidencias/relato.md.
